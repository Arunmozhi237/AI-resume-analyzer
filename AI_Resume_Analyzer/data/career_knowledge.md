# Career and Skills Knowledge Base

## Resume evidence
Strong resumes connect skills to outcomes. Write concise bullets with an action,
the technology used, scope, and a measurable result where it is truthful. For
example: "Built a FastAPI service that reduced report processing time by 35%."
Use the same terminology as the job description when it accurately describes
your experience; never claim skills, certificates, or results you do not have.

## Python and backend engineering
For Python backend roles, employers commonly look for readable Python, API
design, SQL/data modelling, testing, Git, authentication, logging, error
handling, and deployment. A useful portfolio project exposes documented API
endpoints, has tests, validates input, and explains design trade-offs.

## Data and machine learning
For data/ML roles, show the full workflow: data cleaning, exploration,
feature/model choices, evaluation metrics, reproducibility, and deployment or
communication of results. Learn the requested framework by building a small,
documented project rather than only listing a course. Explain precision,
recall, F1, and why a chosen metric fits the problem.

## Cloud and DevOps
Docker packages an application and its dependencies consistently. For cloud or
DevOps requirements, demonstrate a Dockerfile, environment-based
configuration, CI checks, and basic deployment knowledge. Kubernetes is most
useful after understanding containers, networking, and deployment concepts.

## Interview preparation
Prepare STAR stories for projects, teamwork, setbacks, and impact. For every
listed technical skill, be ready to explain one concrete use, a trade-off, and
how you tested or evaluated the result. Practise questions directly connected
to the most important missing or matching requirements in the job description.

## Learning roadmap design
Prioritize a small number of job-critical gaps. For each skill, set a learning
goal, build one observable project artifact, request feedback, and update the
resume only after gaining real evidence. A practical 12-week roadmap is often:
weeks 1-4 foundations; weeks 5-8 a focused project; weeks 9-12 polish,
deployment, documentation, and interview practice.
